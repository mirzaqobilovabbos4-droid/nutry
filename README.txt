REJA BOT — RAILWAY

1. Railway'da yangi Project oching.
2. GitHub orqali shu loyihani deploy qiling yoki ZIP ichidagi fayllarni GitHub repository'ga yuklang.
3. Railway -> Variables bo'limiga kiring.
4. BOT_TOKEN nomli variable yarating va @BotFather bergan bot tokenini kiriting.
5. Ixtiyoriy: BOT_NAME = Abbos
6. Deploy qiling.

python bot.py

- 5 daqiqa oldin eslatma yuboradi.
